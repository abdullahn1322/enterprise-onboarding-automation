# Naming Standards

## Purpose

This document defines the naming standards used throughout the Enterprise Onboarding Automation project. Consistent naming conventions improve administration, automation, troubleshooting, and auditing.

---

## User Accounts

| Attribute | Standard | Example |
|-----------|----------|---------|
| Username | firstname.lastname | sarah.chen |
| Display Name | First Last | Sarah Chen |
| Email Address | firstname.lastname@apexinnovations.com | sarah.chen@apexinnovations.com |

---

## Security Groups

| Type | Format | Example |
|------|--------|---------|
| Security Group | SG-Department | SG-Finance |
| Microsoft 365 Group | M365-Department | M365-Finance |

---

## Administrative Roles

Administrative roles are assigned using the principle of least privilege.

Examples:

- User Administrator
- Groups Administrator
- Global Reader

Global Administrator should only be assigned when absolutely necessary.

---

## Benefits

- Consistent identity management
- Easier automation
- Better auditing
- Simplified troubleshooting
