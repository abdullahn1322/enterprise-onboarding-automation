# Project Roadmap

## Project Overview

This project simulates the implementation of an enterprise Identity and Access Management (IAM) environment for Apex Innovations using Microsoft Entra ID, Microsoft Graph, and PowerShell.

The roadmap below outlines the planned implementation phases.

---

# Phase 1 – Project Planning ✅

- Company Profile
- Business Requirements
- Naming Standards
- Organization Structure
- Office Locations

Status: Completed

---

# Phase 2 – Identity Foundation ✅

- Create users
- Populate user attributes
- Create department security groups
- Configure managers
- Verify group membership

Status: Completed

---

# Phase 3 – Access Management ✅

- Create Enterprise Applications
- Assign application access
- Design RBAC model
- Document Access Control Model

Status: Completed

---

# Phase 4 – Identity Automation 🚧

Planned tasks:

- PowerShell onboarding automation
- User update automation
- Department transfer automation
- User offboarding automation

Status: In Progress

---

# Phase 5 – Reporting 📋

Planned tasks:

- User inventory report
- Group membership report
- Enterprise application report
- Identity audit report

Status: Planned

---

# Phase 6 – Project Completion 📌

Planned tasks:

- Final documentation review
- Architecture diagram
- README improvements
- GitHub screenshots
- Project validation

Status: Planned
