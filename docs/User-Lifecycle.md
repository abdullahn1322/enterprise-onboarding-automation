# User Identity Lifecycle

## Overview

The project automates the complete employee identity lifecycle using the Joiner, Mover, and Leaver (JML) model.

---

## Joiner

Creates a new employee identity.

Activities include:

- User creation
- Attribute configuration
- Manager assignment
- Security group assignment
- Reporting
- Logging

---

## Mover

Updates employee identity.

Activities include:

- Department changes
- Job title updates
- Office location updates
- Company updates
- Manager updates
- Security group changes
- Reporting
- Logging

---

## Leaver

Securely deprovisions employee identities.

Activities include:

- Account disablement
- Session revocation
- Security group removal
- Reporting
- Logging

---

## Lifecycle Benefits

- Standardized identity management
- Improved security
- Reduced manual administration
- Better audit readiness
